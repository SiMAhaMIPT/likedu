Введение в дифференциальные уравнения

Теория

Что такое дифференциальное уравнение

Дифференциальное уравнение (ДУ) — это уравнение, в котором неизвестная функция связана со своими производными. В отличие от «обычных» уравнений, где мы ищем число, здесь мы ищем функцию. Именно поэтому решения ДУ — это не числа, а формулы.

Обозначение y′ = dy/dx — это производная функции y(x). Обе записи эквивалентны. В диффурах удобнее использовать «дробную» запись, поскольку она позволяет формально обращаться с дифференциалами dy и dx как с сомножителями.

Порядок уравнения

Порядок ДУ — это порядок старшей производной, которая входит в уравнение.

  • y′ + xy = 0 — первого порядка;
  • y″ + y = 0 — второго порядка;
  • y‴ + y″ = 0 — третьего порядка.

Мы изучаем только уравнения первого порядка. В общем виде такое уравнение содержит:

  1. независимую переменную x;
  2. зависимую переменную y = y(x) — функцию;
  3. первую производную y′ = dy/dx.

Стандартные формы записи:

Неявная: F(x, y, y′) = 0   |   Разрешённая: y′ = f(x, y)

Общее и частное решение

Общее решение ДУ первого порядка — это множество всех функций, удовлетворяющих уравнению. Оно содержит одну произвольную постоянную C (потому что мы один раз интегрировали):

y = φ(x, C).

Иногда общее решение не удаётся выразить явно («игрек через икс»). Тогда ответ записывают в виде общего интеграла — неявного соотношения:

Φ(x, y) = C.

Частное решение — это одна конкретная функция, получающаяся из общего решения подстановкой конкретного значения C.

Аналогия. Общее решение — это «семейство кривых» (например, все параболы y = x² + C). Частное решение — одна конкретная кривая из этого семейства, «пришпиленная» к точке.

Задача Коши

Задача с начальным условием y(x₀) = y₀ называется задачей Коши. Алгоритм:

  1. Найти общее решение (с константой C).
  2. Подставить x = x₀ и y = y₀ в общее решение — получится уравнение относительно C.
  3. Найти C и подставить его обратно.

Геометрически задача Коши означает: найти ту интегральную кривую из семейства, которая проходит через заданную точку (x₀, y₀).

Геометрический смысл

Уравнение y′ = f(x, y) в каждой точке плоскости (x, y) задаёт наклон касательной к искомой кривой. Решение — это кривая, у которой в каждой точке наклон совпадает с предписанным. Такие кривые называются интегральными кривыми.

Что нужно уметь для решения ДУ

  • Интегрировать — от простейших табличных интегралов до интегрирования по частям и заменой переменной.
  • Дифференцировать — включая производную от неявно заданной функции.
  • Алгебраически упрощать — группировать, выносить за скобки, разделять переменные.
Важно. Опыт показывает: если у вас хорошо поставлена техника интегрирования, то ДУ даются легко. Если интегралы пока слабоваты — сначала стоит подтянуть их, это сильно упростит жизнь.

Три главных типа ДУ 1-го порядка

В контрольных работах встречаются почти всегда одни и те же три типа. Их и разберём:

  1. Уравнения с разделяющимися переменными — самые простые, решаются «в лоб» делением на g(y).
  2. Однородные уравнения — решаются заменой y = ux, после которой становятся «разделяющимися».
  3. Линейные неоднородные уравнения — решаются методом Бернулли (замена y = uv).

Порядок изучения — именно такой. Каждый следующий тип опирается на предыдущий.

1. Уравнения с разделяющимися переменными

Теория

Определение

Уравнение называется уравнением с разделяющимися переменными, если его можно записать в виде

y′ = f(x) · g(y),

где f(x) зависит только от x, а g(y) — только от y. Иными словами, правая часть «рассыпается» на два множителя, каждый из которых отвечает за свою переменную.

В эквивалентной дифференциальной записи это выглядит так:

g(y) dy = f(x) dx.

Идея метода

Вспомним, что y′ = dy/dx. Тогда

dy / dx = f(x) · g(y).

Формально «перенесём dx»:

dy / g(y) = f(x) dx.

Теперь слева стоит выражение, зависящее только от y, справа — только от x. Их можно отдельно проинтегрировать:

∫ dy / g(y) = ∫ f(x) dx + C.

Константу C добавляем один раз — после взятия любого из интегралов (обычно правого).

Строго говоря, запись «dy/dx = … , переносим dx» — это удобное мнемоническое правило, а не полноценная алгебраическая операция. Тем не менее оно работает и обосновано в курсе анализа через замену переменной в интеграле.

Алгоритм решения

  1. Переписать производную как dy/dx.
  2. Убедиться, что переменные разделяются: справа должно быть произведение «функция от x» × «функция от y». Если нет — этот метод не подходит.
  3. Разделить переменные: всё с y перенести в левую часть, всё с x — в правую:
    dy / g(y) = f(x) dx.
  4. Проинтегрировать обе части:
    ∫ dy / g(y) = ∫ f(x) dx + C.
  5. Упростить. Если удаётся выразить y через x — записать общее решение. Если нет — оставить общий интеграл. Если задано начальное условие — подставить и найти C.

Пример 1 (простой)

Задача

Решить y′ = x / y.

Решение

Шаг 1. Перепишем производную: dy/dx = x/y.

Шаг 2. Переменные разделяются: справа произведение «x» и «1/y», значит f(x) = x, g(y) = 1/y.

Шаг 3. Умножаем обе части на y·dx: y dy = x dx.

Шаг 4. Интегрируем: ∫ y dy = ∫ x dx + C.

Получаем: y²/2 = x²/2 + C.

Шаг 5. Умножаем на 2 и переобозначаем 2C через C:

y² = x² + C.

Это общий интеграл. Можно выразить явно: y = ±√(x² + C).

Пример 2 (задача Коши)

Задача

Найти частное решение y′ = −2xy, если y(0) = 1.

Решение

Шаг 1. dy/dx = −2xy.

Шаг 2. Разделяем переменные: dy/y = −2x dx.

Шаг 3. Интегрируем: ln|y| = −x² + C₁.

Шаг 4. Избавляемся от логарифма: |y| = e−x²+C₁ = eC₁·e−x². Обозначим eC₁ = C (положительная константа). Тогда y = C·e−x².

Шаг 5. Подставляем начальное условие x = 0, y = 1: 1 = C·e0 = C, значит C = 1.

Частное решение:

y = e−x².

Пример 3 (с потерей решений)

Задача

Решить y′ = y².

Решение

Разделяем: dy/y² = dx.

Интегрируем: −1/y = x + C.

Отсюда y = −1/(x + C).

Но! При делении на y² мы потеряли случай y = 0. Проверка: y = 0 даёт y′ = 0 и y² = 0, то есть y = 0 — решение. Его нужно указать отдельно (оно не входит в общее решение ни при каком конечном C).

Ответ: y = −1/(x + C) и y = 0.

Типичные ошибки

  • Забыть проверить потерянные решения. Всегда, когда делите на функцию, которая может быть нулём, проверяйте случай «= 0».
  • Не упрощать константу. Если ∫ даёт x²/2 + C, то после умножения на 2 получится x² + 2C. Правильно переобозначить 2C через C, а не оставлять «двойку».
  • Забыть модуль под логарифмом. ∫ dy/y = ln|y|, а не ln y.
  • Пытаться разделить переменные там, где нельзя. Например, y′ = x + y — не разделяется. Нужен другой метод.
Технический приём «снос константы». Если после интегрирования справа стоит логарифм, константу удобно записывать тоже под логарифмом: вместо +C писать +ln|C|. Это упростит дальнейшее «упаковывание» логарифмов.

2. Однородные дифференциальные уравнения

Теория

Определение

Уравнение y′ = f(x, y) называется однородным, если функция f(x, y) не меняется при одновременном умножении обоих аргументов на произвольное число λ ≠ 0:

f(λx, λy) = f(x, y)   для всех λ ≠ 0.

Говорят ещё, что f — однородная функция нулевой степени.

Эквивалентное определение: f(x, y) зависит только от отношения y/x:

f(x, y) = φ(y / x).

Именно этим мы и будем пользоваться: замена y = ux «вытаскивает» отношение y/x наружу.

Проверка на однородность

В исходное уравнение подставляем λx вместо x и λy вместо y. Производную y′ не трогаем. Если все λ сокращаются и мы приходим к исходному уравнению — оно однородное.

Разберём на примере. Рассмотрим y′ = (x² + y²)/(xy). Подставим:

(λx)² + (λy)² / ((λx)(λy)) = λ²(x² + y²) / (λ²xy) = (x² + y²)/(xy).

Все λ сократились — уравнение однородное.

Контрпример. y′ = x + y. Подставим: λx + λy = λ(x + y). Множитель λ не сократился — уравнение не однородное в этом смысле.

Стандартная замена

Вводим новую функцию u(x) равенством:

y = u·x,    тогда    u = y / x.

Найдём y′. По правилу дифференцирования произведения:

y′ = (ux)′ = u′x + u·x′ = u′x + u.

Это ключевая формула. Её нужно запомнить:

y = ux,    y′ = u′x + u.

Почему это работает

После подстановки y = ux правая часть f(x, y) превращается в f(x, ux) = φ(u) — благодаря однородности все «x» сокращаются. Получается уравнение вида

u′x + u = φ(u),

то есть

u′x = φ(u) − u.

А это уже уравнение с разделяющимися переменными относительно u и x:

du / (φ(u) − u) = dx / x.

Интегрируем, находим u(x), потом делаем обратную замену u = y/x.

Алгоритм решения

  1. Проверить на однородность (мысленно, на черновике).
  2. Проверить на разделяемость: иногда однородное уравнение удаётся разделить «в лоб», и тогда замена y = ux не нужна (но это редкость).
  3. Сделать замену y = ux, y′ = u′x + u.
  4. Упростить: сгруппировать, сократить x, получить разделяющееся уравнение для u.
  5. Разделить переменные и проинтегрировать.
  6. Обратная замена u = y/x.
  7. Проверить потерянные решения (при делении на u, на x, на выражения с y).

Пример 1

Задача

Решить y′ = (x + y) / x.

Решение

Проверка однородности. f(λx, λy) = (λx + λy) / (λx) = (x + y)/x = f(x, y). Все λ сократились — уравнение однородное.

Замена. y = ux, y′ = u′x + u. Подставляем:

u′x + u = (x + ux) / x = 1 + u.

Сокращаем u в обеих частях:

u′x = 1.

Отсюда du/dx = 1/x.

Интегрируем. ∫ du = ∫ dx/x, то есть u = ln|x| + C.

Обратная замена. u = y/x, значит y/x = ln|x| + C.

y = x·ln|x| + Cx.

Пример 2 (со «сбросом» в знаменатель)

Задача

Решить y′ = (x² + y²) / (xy).

Решение

Проверка. Все λ сокращаются — уравнение однородное.

Замена y = ux. Тогда y′ = u′x + u, а правая часть:

(x² + u²x²) / (ux²) = (1 + u²) / u.

Уравнение принимает вид:

u′x + u = (1 + u²)/u = 1/u + u.

Сокращаем u:

u′x = 1/u  ⇒  u du = dx/x.

Интегрируем: u²/2 = ln|x| + C₁.

Умножаем на 2, переобозначаем 2C₁ через C: u² = 2ln|x| + C.

Обратная замена u² = y²/x²:

y² = 2x²·ln|x| + Cx².

Проверка потерянных решений. Мы делили на u. Случай u = 0 означает y = 0. Подставляем в исходное уравнение: 0 = (0 + 0)/0 — формально не определено. Также делили на x (случай x = 0 не имеет смысла для ДУ). Значит, дополнительных решений нет.

Типичные ошибки

  • Забыть проверить на однородность. Если делать замену y = ux в неоднородном уравнении — упрощения не произойдёт, получится каша.
  • Путать y′ и u′. Помните: y′ = u′x + u, а не u′.
  • Забыть обратную замену. Ответ должен быть через y, а не через u.
  • Потерять решения при делении. Особенно при делении на u или на x.
Важно. В 18 случаях из 20 общее решение однородного уравнения удобнее оставлять в виде общего интеграла (неявно). Попытка выразить y явно часто даёт громоздкую и некрасивую формулу.

3. Линейные неоднородные уравнения

Теория

Определение

Уравнение называется линейным неоднородным уравнением первого порядка, если его можно записать в стандартном виде

y′ + P(x)·y = Q(x),

где P(x) и Q(x) — заданные функции (или константы), причём Q(x) ≢ 0.

Почему «линейное»: относительно неизвестной функции y и её производной y′ уравнение линейно — они входят в первой степени, не перемножаются, не стоят под знаком функции. Никаких y², √y, sin y и т.п. быть не должно.

Как узнать линейное уравнение

Признаки:

  • Есть y′ (первая степень).
  • Есть слагаемое вида «коэффициент × y», где коэффициент зависит только от x (или это константа).
  • В правой части — выражение, зависящее только от x (или константа).

Примеры линейных:

  • y′ + 2y = x;
  • y′ − y/x = x²;
  • xy′ + y = 1 (после деления на x);
  • y′ + y·tg x = 1/cos x.

Примеры НЕ линейных:

  • y′ + y² = 0 — квадрат y;
  • y′ = y·sin y — синус от y;
  • yy′ = 1 — произведение y·y′.
Важно. Если уравнение не является ни разделяющимся, ни однородным — с вероятностью 90% это линейное уравнение. Именно поэтому его разбирают третьим и последним.

Метод Бернулли (замена y = uv)

Идея метода: представить искомую функцию как произведение двух вспомогательных функций:

y = u(x) · v(x),

где u и v — новые неизвестные функции. Почему это помогает, станет ясно чуть позже.

Продифференцируем по правилу произведения:

y′ = u′v + uv′.

Подставим в исходное уравнение y′ + P(x)y = Q(x):

u′v + uv′ + P(x)·uv = Q(x).

Сгруппируем второе и третье слагаемые — в них есть общий множитель u:

u′v + u · [ v′ + P(x)·v ] = Q(x).

Вот ключевой момент. У нас одна функция y, но две вспомогательные — u и v. Значит, одну из них мы можем подчинить любому удобному условию. Выберем его так, чтобы выражение в квадратных скобках обратилось в ноль:

v′ + P(x)·v = 0.

Тогда исходное уравнение превратится в простое:

u′v = Q(x).

Получаем систему из двух уравнений:

{  v′ + P(x)·v = 0,
 u′·v = Q(x).

Алгоритм решения

  1. Привести уравнение к стандартному виду y′ + P(x)y = Q(x). Если перед y′ стоит коэффициент — поделить на него.
  2. Замена: y = uv, y′ = u′v + uv′.
  3. Сгруппировать слагаемые: получить u′v + u(v′ + Pv) = Q.
  4. Составить систему: v′ + Pv = 0 и u′v = Q.
  5. Из первого уравнения найти v (это уравнение с разделяющимися переменными). Константу не пишем — достаточно одного частного решения.
  6. Подставить v во второе уравнение и найти u. Здесь уже обязательно добавляем + C.
  7. Записать ответ: y = u·v.
Почему константу из первого уравнения не пишем? Если бы мы написали v = v₀·C₁, то итоговое y = uv всё равно содержало бы произвольную постоянную из второго уравнения. Две константы «сольются» в одну. Поэтому для простоты берём C₁ = 1.

Пример 1 (простой)

Задача

Решить y′ + y = 1.

Решение

Уравнение уже в стандартном виде: P(x) = 1, Q(x) = 1.

Замена: y = uv, y′ = u′v + uv′. Подставляем:

u′v + uv′ + uv = 1  ⇒  u′v + u(v′ + v) = 1.

Система:

v′ + v = 0,    u′v = 1.

Шаг 1. Находим v. Из первого уравнения:

dv/v = −dx  ⇒  ln|v| = −x  ⇒  v = e−x.

(Константу не пишем — она не нужна, см. выше.)

Шаг 2. Находим u. Из второго уравнения:

u′ · e−x = 1  ⇒  u′ = ex  ⇒  u = ex + C.

(Здесь уже добавляем константу — обязательно.)

Шаг 3. Собираем ответ:

y = uv = (ex + C)·e−x = 1 + Ce−x.

y = 1 + C·e−x.

Пример 2 (с дробью)

Задача

Решить y′ + y/x = x.

Решение

Замена: y = uv. Подставляем:

u′v + uv′ + uv/x = x  ⇒  u′v + u(v′ + v/x) = x.

Система:

v′ + v/x = 0,    u′v = x.

Шаг 1. Из первого уравнения:

dv/v = −dx/x ⇒ ln|v| = −ln|x| = ln(1/|x|) ⇒ v = 1/x.

Шаг 2. Подставляем v во второе уравнение:

u′ · (1/x) = x ⇒ u′ = x² ⇒ u = x³/3 + C.

Шаг 3. Собираем:

y = (x³/3 + C)/x = x²/3 + C/x.

Пример 3 (с задачей Коши)

Задача

Решить y′ − 2y/x = x³, если y(1) = 0.

Решение

Замена y = uv. Подставляем:

u′v + u(v′ − 2v/x) = x³.

Система: v′ − 2v/x = 0,   u′v = x³.

Шаг 1. Первое уравнение: dv/v = 2dx/x ⇒ ln|v| = 2ln|x| = ln(x²) ⇒ v = x².

Шаг 2. Второе уравнение: u′·x² = x³ ⇒ u′ = x ⇒ u = x²/2 + C.

Шаг 3. Общее решение: y = x²(x²/2 + C) = x⁴/2 + Cx².

Шаг 4. Задача Коши. Подставляем x = 1, y = 0: 0 = 1/2 + C ⇒ C = −1/2.

y = x⁴/2 − x²/2 = (x⁴ − x²)/2.

О связи с методом вариации постоянной

Существует второй, равноправный способ решения линейных уравнений — метод вариации произвольной постоянной (метод Лагранжа). Идея: сначала решить однородное уравнение y′ + Py = 0 (получится y = C·y₀(x)), затем «варьировать» константу: заменить C на функцию C(x) и подставить в исходное уравнение.

Оба метода дают одинаковый результат. Метод Бернулли (замена y = uv) более «механический» и обычно проще для начинающих — поэтому мы используем именно его.

Типичные ошибки

  • Забыть привести к стандартному виду. Если перед y′ стоит коэффициент, делим на него. Например, xy′ + y = x² сначала преобразуется в y′ + y/x = x.
  • Спутать, куда подставлять v. v из первого уравнения подставляется во второе, а не в исходное.
  • Не добавить константу во втором шаге. Если её не поставить при нахождении u, получится не общее, а частное решение.
  • Забыть написать финальное y = uv. Ответ должен быть через y и x, а не через u и v.
Проверка. Общее решение линейного уравнения всегда можно подставить в исходное уравнение и убедиться, что получилось тождество. Это хорошая привычка — особенно в контрольной работе.
