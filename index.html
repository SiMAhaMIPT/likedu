Введение в дифференциальные уравнения

Теория

Дифференциальное уравнение (ДУ) — уравнение, в котором неизвестная функция связана со своими производными. Порядок ДУ — порядок старшей производной.

Мы рассматриваем ДУ первого порядка. В общем виде оно содержит:

  1. независимую переменную $x$;
  2. зависимую переменную $y = y(x)$ — функцию;
  3. первую производную $y' = \dfrac{dy}{dx}$.

Стандартная запись: $F(x, y, y') = 0$, либо разрешённая относительно производной: $y' = f(x, y)$.

Общее решение — множество всех функций, удовлетворяющих уравнению. Обычно содержит произвольную постоянную $C$: $y = \varphi(x, C)$.
Общий интеграл — та же идея, но функция задана неявно: $\Phi(x, y) = C$.
Частное решение — конкретная функция при фиксированном $C$.

Задача с начальным условием $y(x_0) = y_0$ называется задачей Коши. Из общего решения подстановкой $x_0, y_0$ находят $C$ и получают частное решение.

Важно: для решения ДУ нужно уверенно интегрировать и дифференцировать, включая производную от неявно заданной функции.

В этом тренажёре мы разберём три главных типа уравнений 1-го порядка, которые составляют 95% контрольных работ:

  1. уравнения с разделяющимися переменными;
  2. однородные уравнения;
  3. линейные неоднородные уравнения.

1. Уравнения с разделяющимися переменными

Теория

Определение. Уравнение вида $$y' = f(x)\, g(y)$$ называется уравнением с разделяющимися переменными.

Алгоритм решения

  1. Записать производную как $\dfrac{dy}{dx}$: $$\frac{dy}{dx} = f(x)\,g(y).$$
  2. Разделить переменные: перенести всё с $y$ влево, всё с $x$ — вправо: $$\frac{dy}{g(y)} = f(x)\,dx.$$
  3. Проинтегрировать обе части: $$\int \frac{dy}{g(y)} = \int f(x)\,dx + C.$$
  4. Упростить и записать общий интеграл или общее решение. Если задано начальное условие — найти $C$.
Осторожно! При делении на $g(y)$ или на функцию от $x$ можно потерять решения. Проверяйте, не являются ли $g(y)=0$ или соответствующие $x$ решениями уравнения.

Пример 1

Решить $y' = \dfrac{x}{y}$.

Перепишем: $\dfrac{dy}{dx} = \dfrac{x}{y}$. Разделяем: $y\,dy = x\,dx$. Интегрируем:

$$\int y\,dy = \int x\,dx + C \;\Rightarrow\; \frac{y^2}{2} = \frac{x^2}{2} + C.$$

Умножим на 2 и переобозначим $C$: общий интеграл $$\boxed{\,y^2 = x^2 + C\,}.$$

Пример 2 (задача Коши)

Найти частное решение $y' = -2xy$, если $y(0) = 1$.

$\dfrac{dy}{dx} = -2xy$. Разделяем: $\dfrac{dy}{y} = -2x\,dx$. Интегрируем: $\ln|y| = -x^2 + C$. Тогда $y = C_1 e^{-x^2}$.

Подставляем $x=0,\;y=1$: $1 = C_1 e^0 \Rightarrow C_1 = 1$. Частное решение: $\boxed{y = e^{-x^2}}$.

Технический приём. Если в правой части появляется логарифм, константу удобно тоже писать под логарифмом: вместо $+C$ писать $+\ln|C|$ — это упрощает дальнейшие преобразования.

2. Однородные дифференциальные уравнения

Теория

Определение. Уравнение $y' = f(x,y)$ называется однородным, если функция $f$ удовлетворяет условию $$f(\lambda x, \lambda y) = f(x, y) \quad \forall \lambda \neq 0.$$

Проверка на однородность

В исходное уравнение вместо $x$ подставляем $\lambda x$, вместо $y$ — $\lambda y$; производную $y'$ не трогаем. Если все $\lambda$ сокращаются и получается исходное уравнение — оно однородное.

Стандартная замена

$$y = u x, \qquad y' = u' x + u,$$ где $u = u(x)$ — новая неизвестная функция.

После подстановки уравнение гарантированно превращается в уравнение с разделяющимися переменными относительно $u$ и $x$.

Пример

Решить $y' = \dfrac{x+y}{x}$.

Проверка: $f(\lambda x, \lambda y) = \dfrac{\lambda x + \lambda y}{\lambda x} = \dfrac{x+y}{x} = f(x,y)$ — однородное.

Замена $y = ux$, $y' = u'x + u$:

$$u'x + u = \frac{x + ux}{x} = 1 + u.$$

Отсюда $u'x = 1$, то есть $\dfrac{du}{dx} = \dfrac{1}{x}$. Интегрируем: $u = \ln|x| + C$. Обратная замена $u = y/x$:

$$\boxed{\,y = x \ln|x| + Cx\,}.$$
Осторожно! Если в ходе решения вы делите на что-то, что может обращаться в ноль (например, на $u$, на $x$, на выражение с $y$), проверьте, не является ли это «что-то = 0» отдельным решением.

3. Линейные неоднородные уравнения

Теория

Определение. Уравнение вида $$y' + P(x)\,y = Q(x)$$ называется линейным неоднородным уравнением первого порядка. Здесь $P(x)$ и $Q(x)$ — заданные функции (или константы), $Q(x) \not\equiv 0$.

Если переменные разделить не удалось и уравнение не однородное — в 90% случаев перед вами именно линейное уравнение.

Метод Бернулли (замена $y = uv$)

Ищем решение в виде произведения двух функций: $$y = u(x)\cdot v(x), \qquad y' = u'v + uv'.$$

Подставляем в уравнение: $$u'v + uv' + P(x)\,uv = Q(x).$$ Группируем слагаемые с $u$: $$u'v + u\bigl(v' + P(x)v\bigr) = Q(x).$$

Система: $$\begin{cases} v' + P(x)\,v = 0,\\[4pt] u'\,v = Q(x). \end{cases}$$
  1. Из первого уравнения находим $v$ (константу не пишем — она «поглотится» на следующем шаге).
  2. Подставляем $v$ во второе уравнение и находим $u$ (здесь уже добавляем $+C$).
  3. Записываем $y = uv$.

Пример

Решить $y' + y = 1$.

Замена $y = uv$, $y' = u'v + uv'$: $u'v + uv' + uv = 1 \Rightarrow u'v + u(v' + v) = 1$.

Система: $\begin{cases} v' + v = 0 \\ u'v = 1 \end{cases}$.

Из первого: $\dfrac{dv}{v} = -dx \Rightarrow \ln|v| = -x \Rightarrow v = e^{-x}$.

Второе: $u' e^{-x} = 1 \Rightarrow u' = e^{x} \Rightarrow u = e^{x} + C$.

Итого: $y = uv = (e^{x} + C)\,e^{-x} = 1 + Ce^{-x}$.

Ответ: $\boxed{y = 1 + Ce^{-x}}$.

Если после интегрирования получается «некрасивый» ответ, часто выгоднее оставить результат в виде общего интеграла — это нормально и не считается ошибкой.
